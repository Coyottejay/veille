# Veille

Tape `/veille` dans Claude, reçois un condensé court des dernières fuites de données, leaks et
incidents sécurité. C'est tout.

Rien à installer sur ton ordinateur. Pas de serveur, pas de clé, pas de compte à créer.

## Installer — 1 minute

Il te faut Claude (compte Pro ou plus), sur le site ou l'application.

1. Ouvre **Paramètres** → **Plugins**.
2. Clique **Ajouter** → **Ajouter depuis un dépôt**.
3. Colle ceci :

   ```
   Coyottejay/veille
   ```

4. Clique **Synchroniser**, puis **Installer** sur le plugin « Veille ».

Un réglage à vérifier une fois : **Paramètres → Capacités → « Exécution de code cloud et création
de fichiers »** doit être **activé**. Sans lui, les plugins ne se chargent pas.

## Utiliser

Dans une conversation :

```
/veille
```

Pour ne voir qu'un sujet :

```
/veille phishing
```

Les tags disponibles changent avec l'actualité. Si ton filtre ne trouve rien, Claude te dit
lesquels existent aujourd'hui.

## Se mettre à jour

Rien à faire. Le contenu est lu à chaque appel — tu as toujours la dernière version.

(Très rarement, si l'outil lui-même change, tu verras un bouton « Mettre à jour » dans
Paramètres → Plugins. Un clic.)

## Ce que c'est, ce que ce n'est pas

Un partage entre potes. Pas un produit, pas un service, aucune garantie. Les liens mènent aux
sources, va voir par toi-même.
